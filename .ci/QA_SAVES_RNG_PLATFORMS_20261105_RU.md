## Новый подтверждённый дефект и исправление

В старом обработчике JSON-сохранений `safeActivity` и `safeJournal` вызывали `String(value)` для неконтролируемых вложенных объектов. JSON со свойством `{"toString":null}` вызывал `TypeError: Cannot convert object to primitive value` во время импорта. Это подтверждено старым тестовым прогоном **41926010271 (FAIL)** с настоящим Chromium.

Исправлено в `.ci/patch-p0-import-text.py`: текстовые метаданные принимаются только из примитивов, некорректные объекты отбрасываются; невалидные параметры архивного повтора рулетки не исполняются. **41926048046 (PASS)**: два кошелька, истории, откат и холодный перезапуск прошли.

## Важно о сертификатах и установке

Новые Android APK — **debug/QA, только для отдельной тестовой установки**. При переходе с APK, подписанной другим ключом, Android откажет в обновлении; удаление приложения может стереть данные. Постоянная подпись не настроена; владелец решил пока **не оплачивать и не настраивать сертификаты**.

Для iOS получены только сборки симулятора, не подписанные IPA для физических устройств. Mac ZIP — кросс-сборки без Apple Developer ID, без нотариализации и без нативной проверки нового патча.
