# NEON CASINO ROYALE — QA v1.7.4 (27.10.2026)

## Выполнено

- `npm test`: **успешно**, включая все старые наборы проверок 44 игр, ставок, возвратов, двух кошельков, сохранений и мультиоконной защиты, плюс новый `tests/test_v174.cjs`.
- Новые сценарии: аварийный перезапуск Android WebView при зарезервированной ставке 140 фишек, восстановление без ожидания истечения lease и без двойной компенсации; защита обычного второго браузерного окна осталась активной.
- `node --check web/app.js`: успешно.
- `tools/check_project.py` и `tools/check_mobile.py`: успешно; Android и браузерные локальные ресурсы идентичны побайтово; манифест не требует INTERNET.
- Chromium 390 и 1440 пикселей: 44 навигационных пункта, переключение Free/Daily, режим Eco, отсутствие JS-ошибок и горизонтального переполнения. Для обхода блокировки навигации в изолированном Chromium тестовый стенд вставлял **локальные** HTML/CSS/JS непосредственно в страницу. Загрузка через Android WebView не проверялась.
- Добавлен необязательный Android-эмуляторный smoke test в GitHub Actions. Он **не запускался**.

## Осталось непроверенным

- `gradle :app:assembleDebug` и подпись штатного APK: в этом контейнере отсутствуют Android SDK, Gradle, Android build tools, доступа к загрузочным адресам SDK нет.
- Установка, запуск и работа WebView на реальном Android, включая Android 15/16.
- Работа picker для JSON-файла на физических телефонах; тестировался код и статические контракты, не ОС.
- Производительность на слабых телефонах и реальный FPS.
- Сохранение прогресса при обновлении ранее выданных APK, подписанных несовместимыми сертификатами.

**Вывод:** проект стал устойчивее на уровне проверенных механизмов и тестов, но *не является проверенным устанавливаемым APK*. Следующая объективная проверка — сборка через Android SDK и установка на эмулятор/телефон.
