# NEON CASINO ROYALE — Android v1.7.4 (исправленный проект)

**Статус:** полноценный исходный Android-проект для **стандартной** сборки через Android SDK/Gradle. **НЕ готовый APK**. Здесь отсутствует Android SDK, поэтому реальный APK не собран, на смартфон не устанавливался и на эмуляторе не запускался. Не используйте старые экспериментальные APK, полученные путём ручной упаковки DEX/ZIP.

## Что исправлено

- Все **44 существующие игры** сохранены, оба кошелька и игровые дни остались независимыми.
- Если процесс WebView аварийно завершился, приложение создаёт новый игровой WebView или показывает понятный экран восстановления. При возвращении кошелька прерванная ставка восстанавливается из сохранения; в отдельном автоматическом тесте проверено отсутствие повторной выдачи.
- Исправлена задержка повторного запуска после сбоя WebView: только внутри **единственной Android Activity** разрешён немедленный возврат владения кошельком. В обычном браузере защита от двух одновременных окон сохранена.
- Встроенная страница загружает только разрешённые локальные ресурсы, ограничена Content Security Policy; внешние страницы и запросы заблокированы. **Разрешения INTERNET нет**.
- Экспорт сохранения теперь подтверждается в интерфейсе только после успешной записи выбранного пользователем JSON-файла. Отмена или ошибка записи вызывает сообщение о неудаче.
- Кнопка «Назад» закрывает модальное окно или меню; если они закрыты, предлагает выйти.
- Эко-режим графики по умолчанию учитывает уменьшение движения / небольшой объём памяти, при ручном выборе пользовательская настройка сохраняется. Увеличены области нажатий на небольших экранах.
- Ошибка загрузки ресурсов отображается как экран восстановления вместо пустого WebView.
- Отладочный пакет имеет отдельный ID `com.neon.play.simulator.qa`, не конфликтующий со старым приложением. Это **отдельное хранилище**; прежний прогресс автоматически не переносится.

## Как получить нормальный APK на MacBook

1. Установить **Android Studio** (developer.android.com/studio) и Android SDK Platform 35, Build-Tools 35.0.0, JDK 17.
2. Открыть **всю папку проекта** `NEON_CASINO_ANDROID_v1_7_4_HARDENED` в Android Studio (не один HTML-файл).
3. Дождаться Gradle Sync; нажать **Build → Build APK(s)**.
4. Установщик будет здесь: `app/build/outputs/apk/debug/app-debug.apk`. Это APK, подписанный отладочным ключом Android Studio и проверяемый стандартным `apksigner`.
5. Рекомендуется сперва установить на тестовый телефон, проверить запуск всех экранов, импорт/экспорт JSON и сохранение виртуальных фишек после перезапуска.

### GitHub Actions — сборка без локальной Android Studio

Загрузить **содержимое** папки проекта в отдельный предназначенный для этого GitHub-репозиторий. Открыть **Actions → NEON ROYALE — Android APK (verified) → Run workflow**. После успеха скачать артефакт `NEON-ROYALE-v1.7.4-QA-APK`. Включаемый по желанию параметр `emulator_smoke` запускает Android-эмулятор и проверяет открытие приложения (работает дольше). **Этот workflow здесь не запускался**, подтверждённого GitHub-артефакта пока нет.

### Почему предыдущий APK не устанавливался

Ранее APK упаковывался вручную и не проходил нормальную SDK/Gradle-сборку. Проверка ZIP или подписи сама по себе не подтверждала совместимость с Android. Новая версия предназначена для сборки штатными инструментами. Без фактической установки утверждать, что ошибка устранена полностью, нельзя.

### Предыдущий прогресс

Перед удалением старой версии нужно экспортировать данные через меню кошелька. Отдельный QA-пакет `com.neon.play.simulator.qa` не видит данные другого пакета автоматически. Импорт сохранения производится через кошелёк. Не используйте тестовую подпись как постоянный релизный сертификат.
