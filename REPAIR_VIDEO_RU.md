# Исправление ошибки установки NEON CASINO — по видео пользователя

На записи 27 октября 2026 г. виден выбор `NEON_CASINO_v1_7_2_ANDROID_V2_DIAGNOSTIC.apk` в файловом менеджере и стандартное сообщение установщика: **«Не удалось установить приложение. Возникла проблема с файлом приложения».**

Это подтверждает **отказ до запуска игры**. Сообщение не содержит кода `INSTALL_FAILED_*`, поэтому точная внутренняя причина остаётся неизвестной. Прежний диагностический APK сформирован вручную: его целостность ZIP и наличие v2-подписи недостаточны для подтверждения совместимости с PackageInstaller.

## Что изменено в проекте

- Это полноценный Android Gradle-проект с AndroidManifest.xml в исходном XML, Java-классом Activity, WebView, встроенными файлами игры и стандартной сборкой APK через Android SDK 35.
- Никаких платежей, сетевых разрешений и загрузок с внешних серверов. Все 44 игры и кошельки взяты из существующего проекта, не переписаны заново.
- Тестовый APK имеет **новое имя пакета `com.neon.play.simulator.qa`**, отличное от предыдущего `com.neon.play.simulator`, и название **NEON ROYALE TEST**. Это помогает исключить конфликт подписи при установке и не затрагивает установленный старый экземпляр. Сохранения из старой версии не импортируются автоматически.
- GitHub Actions сначала проверяет игры, затем использует официальные инструменты Android `Gradle`, `zipalign`, `apksigner`; публикует отладочный APK только при успешных проверках.
- Скрипт `DIAGNOSE_INSTALL_MAC.command` записывает реальный код установки (`INSTALL_FAILED_*`) через USB/ADB, не удаляя прежнюю версию.

## Как собрать на Mac

1. Скачайте [Android Studio](https://developer.android.com/studio) и откройте им **корень распакованного проекта**.
2. Дождитесь Gradle Sync и разрешите загрузку требуемых SDK/Gradle; Интернет нужен один раз на Mac, не для самого симулятора.
3. `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`.
4. Файл находится по пути `app/build/outputs/apk/debug/app-debug.apk`. Если доступен только новый интерфейс Android Studio, используйте поиск действий (`Shift` дважды) по `Build APK`.
5. Скопируйте этот файл на телефон и установите. Это **настоящий APK**, подписанный автоматически стандартной debug-подписью; **сейчас в архиве только исходники, готового APK нет**.
6. Для точного диагноза ошибки подключите телефон к Mac, включите USB debugging и выполните `DIAGNOSE_INSTALL_MAC.command` — полученный `ANDROID_INSTALL_RESULT.txt` содержит причину в виде кода.

## Альтернатива — GitHub Actions

Создайте **отдельный приватный репозиторий**, загрузите в него содержимое проекта, в том числе скрытую папку `.github`, затем откройте Actions → Build and verify NEON CASINO APK → Run workflow. После успешной сборки скачайте Artifact `NEON-ROYALE-v1.7.3-QA-APK` и извлеките `app-debug.apk`.

## Не делать

- Не пытаться чинить вручную собранный APK только дополнительными подписями.
- Не удалять установленную старую версию, пока не экспортировали прогресс. Тестовая версия с `.qa` ставится **параллельно**.
- Не считать проект успешно установленным, пока на телефоне не пройдена реальная установка и запуск.
