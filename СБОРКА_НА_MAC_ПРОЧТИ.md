# NEON CASINO ROYALE v1.7.4 — сборка настоящего APK

**Это исходный проект со скриптом автоматической сборки, а не готовый APK.** Для сборки нужен Mac c Android Studio / официальным Android SDK и доступ в интернет для Gradle.

1. Распакуй ZIP **целиком** на Mac.
2. Установи Android Studio с SDK Platform 35, Android SDK Build Tools 35.0.0 и JDK 17 (обычно Java есть внутри Android Studio).
3. Запусти `СОБРАТЬ_APK_НА_MAC.command` двойным кликом. Если macOS не открывает его, открой Terminal в папке проекта и запусти `bash ./СОБРАТЬ_APK_НА_MAC.command`.
4. При успехе в той же папке появится **NEON_CASINO_ROYALE_v1_7_4_QA_ANDROID.apk**, Finder покажет его расположение.
5. Скопируй полученный APK на Android и установи. Для тестового приложения имя пакета **com.neon.play.simulator.qa**, поэтому оно не перезапишет старую версию. Старый прогресс не переносится автоматически; экспортируй его отдельно.

Скрипт не создаёт вручную подписи и не имитирует установку: он запускает **официальный Android Gradle Plugin**, затем проверяет выравнивание `zipalign`, сертификат `apksigner`, ресурсы игры и отсутствие разрешения INTERNET. Журнал сохраняется в `APK_BUILD_LOG.txt`. Если компоненты не установлены, пишет, что требуется добавить.

Если желаешь собирать без Mac, см. `.github/workflows/build-android.yml` — готовый сценарий GitHub Actions в отдельном репозитории проекта. Его запуск здесь не производился.
